# 💼 Employee Payroll System

Employee Payroll System is a full-stack web application designed to manage employee records, salaries, and payroll operations efficiently. It allows administrators to perform CRUD operations on employees, calculate salaries, and maintain organized payroll data through an intuitive interface.

---

## ✨ Key Features

- Employee record management (Add, Update, Delete, View)
- Salary and payroll calculation
- RESTful API integration
- User-friendly interface
- Database storage using JSON static files

---

## 🛠️ Tech Stack

**Frontend:**
- EJS (Embedded JavaScript Templates)
- CSS

**Backend:**
- Node.js
- Express.js

**Database:**
- JSON Static Files (File-based storage)

---

## 🎯 Project Purpose

This project was built to demonstrate full-stack development concepts including CRUD operations, REST APIs, server-side rendering, and data management using Node.js and Express.
